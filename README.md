**🧮 Python Calculator using Tkinter**

**📌 Project Overview**

This is a simple GUI Calculator built using Python and Tkinter.
The calculator performs basic arithmetic operations like addition, subtraction, multiplication, and division.

This project helped me understand:

GUI development using Tkinter

Event handling in Python

Functions and lambda expressions

Basic expression evaluation

**🚀 Features**

✔ Clean and simple user interface
✔ Basic arithmetic operations (+, −, ×, ÷)
✔ Decimal number support
✔ Clear (C) button
✔ Error handling for invalid expressions

**🛠 Technologies Used**

Python

Tkinter (Python GUI Library)

**▶ How to Run the Project**
Step 1: Install Python

Make sure Python is installed on your system.

Check version:

python --version

Step 2: Run the file
python calculator.py


The calculator window will open.

**🧠 Working Logic**

Button clicks call the press() function

The calculate() function evaluates the expression using eval()

The clear() function clears the input field

Try/Except block handles invalid inputs
